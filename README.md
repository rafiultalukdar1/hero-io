# HERO.IO

## Description
HERO.IO is a React-based website that serves as a central hub for productivity apps.  
Users can browse popular apps, click download links, and view detailed app information.  
The site offers a modern UI and smooth UX for a fast, easy, and engaging experience.  
It features Trending Apps, Installation details, and download/review statistics.

## Technologies
- **React** – Build UI components  
- **React DOM** – Render components in browser  
- **React Router** – Page navigation  
- **Tailwind CSS** – Quick styling  
- **Lucide React** – Icons  
- **React Spinners** – Loading indicators  
- **React Toastify** – Notifications  
- **Recharts** – Charts & graphs
